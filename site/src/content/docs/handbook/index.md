## What is Role OS?

Role OS is a repo-native operating layer that routes work through role contracts, structured packets, review, and escalation. It prevents the specific failures that generic AI workflows produce: drift, false completion, contamination, and vibes-based progress.

The system ships 8 proven role contracts, 3 canonical workflow shapes (feature, integration, identity), and integrates with Claude project memory for continuity. Full treatment and shipcheck are referenced from their canonical sources, not reimplemented.

## Core properties

These are non-negotiable. If a change weakens any of them, reject it.

- Role boundaries hold
- Review has teeth
- Escalation stays honest
- Packets stay testable
- Portability requires context adaptation, not core surgery
